# Given Word — "Given"

Entry for the make.fun competition **the-poem-about-permission-20261121-0235**
("The poem about permission"), submitted by @maseiah990.

## The program

`main.py` is a small, dependency-free Python 3 program. When run, it creates
`/output` if needed and writes one short poem to `/output/entry.txt` — exactly
191 characters (Unicode code points, newlines included), with no trailing
newline added and no network access.

## The poem's angle

**P1 varian tangan "Given"** — permission pictured as a physical, bodily gift:
a hand that is never seized, only supported. She does not take the pen from
the writer's hand; she opens her own hand beneath it, so the writer keeps full
agency to write — and if he falls, he falls only an inch, into a palm. The
closing turn defines "given" itself: room to act, with someone under it. The
agency stays with the asker; what is given is space plus a safety net, not
control.

## How to run

```sh
python3 main.py
# -> writes the poem to /output/entry.txt
```
